Passo a passo no Excel + exercícios com correção automática. Faça na ordem. Use a planilha 3_Modelos_Excel.xlsx junto.

0. Preparar o Excel (5 min)

O Solver é um suplemento que vem desligado. Faça isso uma vez só.

  1. Arquivo → Opções → Suplementos.
  2. Embaixo, em Gerenciar, escolha Suplementos do Excel e clique em Ir...
  3. Marque Solver e dê OK.
  4. Pronto: aparece Dados → Solver (canto direito da faixa).
No Excel em português as fórmulas usam ; como separador: =SOMARPRODUTO(B4:C4;B5:C5).

A receita que serve para TODO problema de PL

  1. Células das variáveis (amarelo): deixe vazias ou com 0. O Solver vai preencher.
  2. Coeficientes: copie a tabela do enunciado (lucros, horas, consumos).
  3. Função objetivo (verde): =SOMARPRODUTO(variáveis;lucros).
  4. Lado esquerdo de cada restrição (azul): =SOMARPRODUTO(variáveis;consumos da linha).
  5. Lado direito: a disponibilidade ou exigência.
  6. Solver: objetivo = célula verde, Máx ou Mín, alterando = células amarelas, restrições = azul ≤/≥ lado direito, marque Tornar variáveis irrestritas não negativas, método LP Simplex.
  7. Resolver → marque os relatórios Resposta e Sensibilidade → OK.

3. Escrever e resolver o dual

Regra de bolso: transpõe tudo. Uma variável dual por restrição do primal.

  1. Primal Max com restrições ≤ → dual Min com restrições ≥.
  2. Coeficientes da FO do dual = lado direito do primal.
  3. Lado direito do dual = lucros do primal.
  4. Cada coluna do primal vira uma linha do dual.

Exemplo (bombons):

PRIMAL  Max 20 P1 + 12,5 P2          DUAL  Min 130 yC + 170 yM
        0,5 P1 + 1/3 P2 ≤ 130  (yC)        0,5 yC + 0,5 yM ≥ 20     (col. P1)
        0,5 P1 + 2/3 P2 ≤ 170  (yM)        1/3 yC + 2/3 yM ≥ 12,5   (col. P2)
        P1, P2 ≥ 0                         yC, yM ≥ 0

Resolvendo no Solver (Mín., restrições ≥): yC = 40, yM = 0, FO = 5.200 = lucro do primal ✓

Interpretação: 1 kg a mais de cereja aumentaria a receita em R$ 40. Menta vale 0 porque já sobra.

Árvore de decisão: passo a passo

  1. Desenhe da esquerda para a direita: □ = decisão, ○ = evento (com probabilidades).
  2. Resolva da direita para a esquerda: em cada ○ faça Σ prob × valor; em cada □ fique com o maior.
  3. Varejista: grande = 0,6·800 + 0,4·máx(40 ; 0,3·20 + 0,7·220 = 160) = 544 vs pequeno = 0,6·270 + 0,4·200 = 242.
EXERCÍCIO 6.2 · Terrenos do hotel

Terreno A: compra 18, retorno 31 se o aeroporto sair perto, revenda 6 se não sair. Terreno B: compra 12, retorno 23, revenda 4. P(aeroporto perto de A) = 0,4; P(perto de B) = 0,6. Opções: A, B, ambos ou nenhum. Calcule o ganho líquido esperado (retorno − compra), em R$ milhões.

Só A: 0,4·(31 − 18) + 0,6·(6 − 18) = 5,2 − 7,2 = −2,0.
Só B: 0,6·(23 − 12) + 0,4·(4 − 12) = 6,6 − 3,2 = 3,4.
Ambos: aeroporto em A (0,4): 13 + (4 − 12) = 5 · em B (0,6): (6 − 18) + 11 = −1 → 0,4·5 + 0,6·(−1) = 1,4.
Nenhum = 0. Decisão: comprar só o terreno B.
